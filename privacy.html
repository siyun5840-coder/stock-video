stock-video 개인정보처리방침

시행일: 2026년 11월 19일

stock-video(이하 "이 도구")는 연결된 유튜브 채널의 운영자가 자기 채널에 영상을 올리기 위해 쓰는 내부 도구입니다. 일반 사용자의 정보를 모으지 않습니다.

1. 이 도구가 받는 Google 사용자 데이터

  • OAuth 토큰: 운영자가 Google 로그인 화면에서 허용하면 발급됩니다. 영상을 올리는 데만 씁니다.
  • 채널 이름·채널 ID (youtube.readonly): 영상이 정해진 채널로 올라가는지 확인하는 데만 씁니다.
  • 업로드 결과 (youtube.upload): 올린 영상의 ID와 공개 상태(비공개·예약 시각)를 받아 업로드 기록에 남깁니다.

이 밖의 데이터(이메일 내용, 연락처, 시청 기록, 구독자 정보, 결제 정보 등)는 요청하지도, 읽지도 않습니다.

2. 사용 목적

운영자 본인의 유튜브 채널에, 운영자가 만든 영상을 비공개 + 예약 공개로 업로드하고 제목·설명·태그·썸네일·AI 사용 표시를 설정하는 것. 다른 목적에는 쓰지 않습니다.

3. 저장 위치와 보관 기간

  • 토큰과 업로드 기록은 운영자 컴퓨터의 로컬 파일에만 저장합니다. 외부 서버·데이터베이스·클라우드에 올리지 않습니다.
  • 토큰은 운영자가 연결을 끊거나(아래 4번) 채널 운영을 그만둘 때 삭제합니다.

4. 공유·판매·광고

Google 사용자 데이터를 누구에게도 팔거나 공유하지 않으며, 광고·분석·AI 모델 학습에 쓰지 않습니다.

stock-video의 Google API 데이터 사용 및 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 연결 끊기·삭제 요청

언제든 Google 계정 → 서드파티 앱 및 서비스에서 stock-video의 접근 권한을 해제할 수 있습니다. 해제하면 토큰은 더 이상 쓸 수 없고, 운영자 컴퓨터의 토큰 파일도 삭제합니다.

6. YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

English summary

stock-video is an internal tool used only by the operator of the connected YouTube channels to upload their own videos. It requests youtube.upload (upload videos and set thumbnails as private, scheduled uploads) and youtube.readonly (read the channel name and ID to confirm the upload target). OAuth tokens and upload records are stored only in local files on the operator's computers; nothing is sent to other servers. Google user data is never sold, shared, used for advertising, analytics or AI model training. stock-video's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
