stock-video

우리 유튜브 채널에, 우리가 직접 만든 주식·코인 시황 해설 영상을 비공개 + 예약 공개로 올리는 내부 도구입니다.

누가 쓰나요? 이 도구는 연결된 유튜브 채널의 운영자만 씁니다. 일반 사용자에게 제공하는 서비스가 아니며, 회원 가입이나 로그인 페이지가 없습니다.

하는 일

  • 매일 만든 해설 영상(데이터·대본·음성·화면)을 운영자 본인의 유튜브 채널에 업로드합니다.
  • 업로드할 때 항상 비공개로 올리고 공개 시각을 예약합니다. 운영자가 공개 전에 확인하고 취소할 수 있습니다.
  • 제목·설명·태그·썸네일과 'AI 사용(변경되거나 합성된 콘텐츠)' 표시를 함께 설정합니다.
  • 업로드 전에 허용된 계정의 채널 이름·ID를 읽어, 정해진 채널이 맞는지 확인합니다.

Google 계정에서 사용하는 권한

  • youtube.upload — 영상 업로드와 썸네일 설정
  • youtube.readonly — 업로드할 채널이 맞는지 확인(채널 이름·ID 읽기)

로그인 정보(토큰)는 운영자 컴퓨터의 파일에만 저장되고, 다른 서버로 보내거나 다른 사람과 공유하지 않습니다. 자세한 내용은 개인정보처리방침을 보세요.

YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 사용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

English. stock-video is an internal tool used only by the operator of the connected YouTube channels. It uploads the market-commentary videos we produce to our own channels as private videos with a scheduled publish time, and sets the title, description, tags, thumbnail and the altered/synthetic content disclosure. It requests youtube.upload (upload videos, set thumbnails) and youtube.readonly (confirm the target channel). OAuth tokens are stored only in a local file on the operator's computers and are never shared. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
